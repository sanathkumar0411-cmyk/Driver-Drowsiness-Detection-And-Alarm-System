 Driver Drowsiness Detection and Alarm System

A real-time driver monitoring system that uses **CNN, YOLO, OpenCV, and Tkinter** to detect driver drowsiness. When signs of drowsiness are detected, the system triggers an alarm to alert the driver and help prevent accidents.

 Technologies Used
- Python
- CNN
- YOLO
- OpenCV
- Tkinter

 Features
- Real-time drowsiness detection
- Face/eye monitoring
- YOLO-based detection
- CNN-based classification
- Alarm alert system
- User-friendly Tkinter interface
